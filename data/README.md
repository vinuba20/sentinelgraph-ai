
# Dataset Instructions

Project dataset: CIC-IDS2017

Store the original CSV files locally in `data/raw/`.

Do not commit raw dataset files to Git.

Keep intermediate outputs in `data/interim/` and
processed outputs in `data/processed/`.

Document the dataset source, selected files, label
mapping, preprocessing steps, and any sampling used.

The data pipeline should record how many rows are
removed during cleaning and why.
